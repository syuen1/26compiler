# CYK 構文解析

`cyk.py` は Yacc 風の文脈自由文法と空白区切りの入力を読み、CYK（Cocke–Younger–Kasami）法で構文解析します。Python 3.10 以降の標準ライブラリだけで動き、LR ディレクトリのプログラムには依存しません。

```console
python3 cyk.py expression.y input.txt
python3 cyk.py --cnf -T --tree expression.y input.txt
```

付属の文法は代入式を扱い、`input.txt` の `ID '=' ID '+' ID '*' ID #` を受理します。`ID` はトークン名であり、字句解析は行いません。文法で引用符付きの終端記号を使う場合、入力でも `'='`、`'+'` のように引用符を残してください。末尾の `#` は入力終端の目印として取り除きます（省略可能）。文法の終端記号として使う場合は引用符付きの `'#'` にしてください。

入力ファイルを省略すると標準入力から読みます。空ファイルまたは `#` だけの入力は空列です。

文法は `%token`、`%start`、`%%`、`:`、`|`、`;` を用います。空右辺と `%empty` を空規則として扱います。コメント・意味アクション・`%prec` は読み飛ばし、優先順位宣言は解析木の選択には適用しません。意味アクション中の文字列に含まれる波括弧には対応していません。

一般の文法を次の順でチョムスキー標準形へ変換します。

1. 新しい開始記号を追加し、空列を導出可能な非終端記号を求める。
2. 空規則を除去し、開始記号が空列を導出するかを別に保存する。
3. 単位規則（`A -> B`）を推移的に除去する。
4. 複数記号の右辺から終端記号を補助非終端記号へ置き換える。
5. 長い右辺を二分化し、`A -> B C` または `A -> token` にする。

補助記号は既存の記号と衝突しない `@CYK0` などを使用します。`--cnf` で変換後の規則を確認できます。

CYK 表の `[i, j]` は入力の i 番目から j 番目までを導出できる非終端記号集合です（1始まり）。長さ1の区間は終端規則で埋め、長さ2以上は各分割位置と二項規則から埋めます。全入力のセルに開始記号があれば受理します。曖昧な文法も解析できます。`--tree` は標準形の解析木を一つ表示し、元の規則の木やすべての解析木は復元しません。空規則・単位規則の除去によって消えたノードは表示されません。

固定した標準形文法に対して解析時間は O(n³)、表と保持する木のノード数は O(n²) です（文法サイズに比例する係数を除く）。空規則除去では nullable な記号の選択を列挙するため、長い右辺を持つ文法では変換規則数が指数的に増えることがあります。

終了コードは受理 `0`、非受理 `1`、文法・入力・ファイルのエラー `2` です。

```console
python3 -m unittest -v test_cyk.py
```
