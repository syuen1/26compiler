# FIRST集合の計算

Python 3.9以上で動作し、追加ライブラリは不要です。

## 実行

これらのファイルを置いたディレクトリで実行してください。

```sh
python3 first.py grammar.txt
python3 first.py grammar.txt --all
python3 first.py grammar.txt -v
python3 first.py grammar.txt -T
python3 first.py grammar.txt --csv first.csv
python3 first.py grammar.txt -T --csv first.csv
```

通常は各非終端記号のFIRST集合を表示します。`--all` を付けると、添付アルゴリズムの定義域に含まれる右辺の全接尾語（空列を含む）のFIRST集合も表示します。

`-v`（`--verbose`）を付けると、最初にFIRSTの定義域 `X = N ∪ PO_p` の全要素を重複なしのリストで表示します。空列は `%empty` と表示します。続いて手順1・2・3の初期化と、反復ごとの4(a)・4(b)の適用理由、更新前後の集合、追加要素を順に表示します。変化がない適用も表示し、追加がなくなった最後の反復で終了を示します。`--all` と併用できます。

## 入力形式

`-T`（`--table`）は、横軸に計算ステップ、縦軸にFIRSTの全引数（非終端記号と右辺の全接尾語）を並べ、各セルにその時点の集合を表示します。ステップ1・2・3はそれぞれ手順1・2・3の直後、以後は4(a)全体、4(b)全体をそれぞれ1ステップとして記録します。最後には変化がない反復も含めます。未初期化のセルは `—`、空集合は `{}`、空列は `%empty` です。

表が端末幅を超える場合は列を分割し、各表に引数の列を繰り返します。`-v` と併用すると詳細ログの後に表を表示します。`-T` は通常の結果一覧の代わりに全引数の表を表示するため、`--all` を付けても表示は同じです。

表では前のステップから変化したセルの末尾に `!` を付けます。未初期化から集合への初期化も変化として扱い、`{} !` のように表示します。

`--csv 出力ファイル` は、同じ表をUTF-8のCSVとして保存します。全ステップを横に並べた1つの表で、端末幅による分割は行いません。変更を表す `!` も含みます。CSVではまだ初期化されていないセルを `--` と表示します（計算済みの空集合は `{}`）。既存の出力ファイルは上書きします。`-T --csv 出力ファイル` と併用すると、端末への表表示とCSV保存を両方行います。`--csv` 単独では通常の結果一覧も端末に表示します。

UTF-8のテキストファイルに、次のように生成規則を書きます。

```text
S : A B ;
A : a A | %empty ;
B : b | %empty ;
```

- 左辺に現れる記号全体を非終端記号集合Nとします。
- 右辺に現れるそれ以外の記号を終端記号集合Tとします。未定義の非終端記号のつもりで書いた名前も終端記号として扱うため、綴りに注意してください。
- 記号は空白で区切ります。`AB` は1記号、`A B` は2記号です。
- `%empty` は空列を表す予約語です。`epsilon` は通常の記号として扱います。空の選択肢（`A : ;` や `A : a | ;`）も空列として扱います。
- 記号を単引用符または二重引用符で囲めます。`':'`、`'|'`、`';'`、`'%empty'` なども終端記号にできます。引用符は記号名の一部として保持されるため、`a`、`'a'`、`"a"` は別の記号です。
- `// ...` と `/* ... */` のコメントに対応します。
- 同じ左辺の規則を複数箇所に書くことができます。
- yacc形式の `%token ID NUM`、`%start expression`、`%%` に対応しています。宣言部と生成規則部は `%%` で区切ります。第2の `%%` 以降の補助コードは読み飛ばします。第2の区切りは省略できます。
- `%token` は終端記号名の列、`%start` は開始記号1つを指定します。開始記号に生成規則があることを検査します。FIRSTは開始記号によらず全引数について計算します。
- `%token` の型・番号・別名指定、意味動作 `{ ... }`、`%prec`、その他のyacc宣言は未対応です。生成規則だけの従来形式も使えます。

## 計算方法

添付アルゴリズムどおり、Nと各右辺の全接尾語の和集合Xを作ります。空列のFIRSTは `{%empty}`、終端記号で始まる列のFIRSTは先頭の終端記号のみ、非終端記号で始まる列のFIRSTは空集合で初期化します。

その後、非終端記号で始まる各接尾語に手順4(a)を適用し、全生成規則に手順4(b)を適用する処理を、集合が変化しなくなるまで繰り返します。各集合への追加のみを行い、候補要素は有限なので停止します。左再帰や相互再帰にも対応します。終端列を導出できない循環のFIRSTは空集合です。

内部では記号列をタプルで表し、非終端記号Aと長さ1の記号列 `(A,)` を同一視します。空列は空タプルで表します。

## FOLLOW計算用の出力

```sh
python3 first.py grammar.txt -o first.txt
```

`-o 出力ファイル` で、FIRSTの全引数（非終端記号と右辺の全接尾語）について最終結果を `X,[a,b,...]` の形式で1行ずつUTF-8で保存します。記号列Xは空白区切り、集合の要素はカンマ区切りです。空列は `%empty`、空集合は `[]` とします。引用符付き終端記号は引用符を保持します。出力例：

```text
%empty,[%empty]
A,[%empty,a]
S,[a,b]
A b,[a,b]
```

`-v`、`-T`、`--csv` と併用できます。既存の出力ファイルは上書きします。入力ファイルや `--csv` の出力先と同じパスは指定できません。

`-o -` はFOLLOW用の内容だけを標準出力へ出します。通常の結果一覧は表示しません。`-v` や `-T` を併用すると、その表示は標準エラー出力へ送ります。`--csv` は引き続き指定ファイルに保存します。

```sh
python3 first.py grammar.txt -o -
python3 first.py grammar.txt -o - > first.txt
```

## yacc形式の入力例

```text
%token ID NUM
%start expression
%%
expression : term expression_tail ;
expression_tail : '+' term expression_tail | %empty ;
term : factor term_tail ;
term_tail : '*' factor term_tail | %empty ;
factor : '(' expression ')' | ID | NUM ;
%%
```
