# 記号表の登録・スコープ管理のデモ

小さな言語のソースを構文解析し、コンパイル時の記号表の変化を表示する Python プログラムです。グローバル変数、関数、仮引数、局所変数を登録します。代入文と関数呼出し文を解析しますが、プログラム自体は実行しません。

## 必要な環境

- Python 3.7 以降（外部 Python ライブラリ不要）
- Graphviz（DOT ファイルを画像や EPS に変換する場合）
- 日本語フォントと Cairo 対応の Graphviz（日本語の EPS 出力の場合）

## 実行方法

```bash
cd ~/github/26compiler/src/symtab
python3 symbol_table_demo.py prog1.txt
```

入力ファイルを省略すると内蔵サンプルを解析します。

```bash
python3 symbol_table_demo.py
python3 symbol_table_demo.py --help
```

入力・出力ファイルの文字コードは UTF-8 です。

## オプション

```text
python3 symbol_table_demo.py [source] [--out-graph FILE.dot] [--septab]
```

| 引数・オプション | 説明 |
|---|---|
| `source` | 入力ソースファイル。省略時は内蔵サンプル。 |
| `--out-graph FILE.dot` | 表示した記号表を Graphviz DOT 形式でも保存する。 |
| `--septab` | 各表を個別の連番 DOT ファイルに保存する。`--out-graph` の指定が必要。 |
| `-h`, `--help` | ヘルプを表示する。 |

DOT 出力を指定しても、標準出力への記号表表示は行います。保存先のディレクトリは事前に用意してください。同名の出力ファイルは上書きします。

## Graphviz 出力

### 全表を1ファイルに保存

```bash
python3 symbol_table_demo.py prog1.txt --out-graph prog1.dot
```

各表を表示順に並べ、矢印で結びます。

### 各表を別ファイルに保存

```bash
python3 symbol_table_demo.py prog1.txt --out-graph prog1.dot --septab
```

`prog1-1.dot`、`prog1-2.dot`、…の順に生成します。各ファイルには1つの表が入り、表同士の矢印はありません。今回の処理では結合版 `prog1.dot` は生成・更新しません。

連番は1から始まり、指定したファイル名の拡張子の前に付けます。出力先に拡張子がなければ `.dot` を付けます。以前の実行で生成された余分な連番ファイルは自動削除しません。

### SVG・EPSへの変換

```bash
dot -Tsvg prog1.dot -o prog1.svg
dot -Teps:cairo prog1.dot -o prog1.eps
```

日本語を含む EPS は、`-Teps` ではなく `-Teps:cairo` を使用してください。

分割した表も個別に変換できます。

```bash
dot -Teps:cairo prog1-1.dot -o prog1-1.eps
```

Graphviz の変換コマンドは別途実行します。Python プログラムが生成するのは DOT ファイルです。

## 記号表と表示タイミング

記号表の項目は次の8項目です。

```text
名前 | 種類 | 値 | スコープ | 番地 | 型 | 引数個数 | 引数型
```

スコープ欄は `global` と `local` の2種類です。関数名によるスコープの区別は記録しません。

記号表は各関数の解析中、次の2箇所で表示します。DOT 出力も同じ時点の状態を保存します。

1. **局所文脈に入った直後**：関数名をグローバル記号表に登録した後、仮引数・局所変数を登録する前。
2. **局所文脈から出るとき**：本体の解析終了後、局所項目を消去する直前。

入口の表示時点では、当該関数の引数個数・引数型はまだ未確定のため `—` です。仮引数列を解析した後に設定します。

出口の表示後、すべての `local` 項目を消去します。グローバル変数と関数の登録情報は残ります。呼出し文や解析終了時には追加の表を表示しません。関数定義がなければ表示する表もありません。

名前は局所、グローバルの順に検索します。同一スコープでの重複宣言はエラーですが、グローバル変数と同名の局所変数は宣言できます。

番地は説明用です。変数・仮引数は各8バイトとして割り当て、グローバル領域を `G+位置`、局所領域を `FP+位置`、関数の入口を `L_関数名` で表します。局所領域の位置は関数ごとに0へ戻します。代入や呼出しを実行しないため、値の欄は更新しません。

## 入力言語

文法全体は `grammar.bnf` を参照してください。

```text
int g;

func f(int a, real b) {
    int x;
    x = a + 1;
    g = x;
}

func main() {
    int x;
    x = 3;
    f(x + 1, (2.5 + 3.5) * 2);
}
```

- 変数・仮引数の型は `int` または `real`。関数の型は `void` として登録します。
- 局所変数宣言は関数本体の先頭にまとめます。
- 文は変数への代入と関数呼出しのみです。関数やブロックの入れ子、戻り値、コメント、文字列リテラルは対応範囲外です。
- 引数なしの `f();` と引数ありの `f(1, 2.5);` を解析できます。
- 呼出し先が関数かどうか、および引数個数の一致を検査します。
- 呼出し先は、その時点で登録済みの関数に限ります。自己再帰は解析できますが、後で定義する関数への呼出しは未宣言エラーになります。
- 代入右辺と実引数の式は評価せず、式内部の名前・型・演算子の妥当性も検査しません。引数は括弧の入れ子を考慮し、最外側のコンマで区切ります。

## ファイル

| ファイル | 内容 |
|---|---|
| `symbol_table_demo.py` | 解析・記号表表示・DOT 出力プログラム |
| `grammar.bnf` | 文法と解析上の規則 |
| `sample.txt` | 仮引数・局所変数の登録例 |
| `sample_output.txt` | `sample.txt` の実行出力例 |
| `prog1.txt` | 同名の局所変数と引数なし呼出しの例 |
| `sample_args.txt` | 引数あり呼出しの例 |

引数ありの例は次のコマンドで解析できます。

```bash
python3 symbol_table_demo.py sample_args.txt --out-graph sample_args.dot --septab
```
