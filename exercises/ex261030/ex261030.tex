 \item フィボナッチ関数のプログラムを以下のように与える．

       \begin{Verbatim}[frame=single]
int a;
fib(int x) {
  if ( x <= 0 ) return(0);
  else if ( x==1 ) return(1);
  else return(fib(x-2)+fib(x-1));
}

main() {
  a = 3;
  printf("%d\n",fib(a));
}
       \end{Verbatim}

       \verb|fib|と\verb|return|の実行と駆動レコードの様子を図式化せよ．
       講義スライドと同様のレベルで図式化すること．
